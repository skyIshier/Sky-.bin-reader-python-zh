========================================
  Sky .bin 配置编辑器 - 项目介绍
========================================

【项目来源】
基于 GitHub 开源项目 Sky-.bin-reader (作者 Miau0x1) 的 C++ 源码，
完整移植为 Python 版本。
原始项目：https://github.com/Miau0x1/Sky-.bin-reader

【项目功能】
《光·遇》游戏配置文件 (.bin) 的读取、编辑、写入工具。
支持将二进制 .bin 文件转换为可读可编辑的 JSON 格式，
修改后再精确转换回 .bin 文件，保证字节级完全一致，
游戏可正常读取。

【核心特性】
1. 精确转换：bin -> json -> bin 完整闭环，256,357 字节逐字节匹配
2. 完整中文翻译：863 个类名 + 5059 个属性名 100% 汉化覆盖
3. 批量处理：支持整个 Levels 目录下所有地图的一键批量转换
4. 保持目录结构：输出自动按地图名分文件夹组织，保留原始文件名
5. 文件对比：内置逐字节对比工具，验证转换正确性
6. 跨平台可用：纯 Python 标准库，无需编译，手机/电脑均可运行

【文件说明】

├─────────────────────────────────────────────────────────┤

【使用方法】
1. 单个文件转换：
   python 单个转换.py
   选择 .bin -> .json（带完整中文翻译）或 .json -> .bin

2. 批量转换：
   python 批量转换.py
   选择 Levels 目录，自动扫描所有 .bin 文件并转换

3. 翻译覆盖率检查：
   python 批量提取-字典用.py <JSON目录路径>
   输出未翻译清单，覆盖率目标 100%

【JSON 结构说明】
转换后的 JSON 包含两部分：

(1) classes（类定义元数据）- 描述每个属性的类型和大小
    例如："propertyType": 0, "objectByteSize": 4, "arrayIndex": 0

(2) BSTNodes（实际游戏数据）- 每个节点的具体数值
    例如："_raw_uint32": 1065353216, "_value": "1.0"

【修改指南】
- 数值属性：修改 "_value" 字段，不要动 "_raw_*" 字段
- 字符串属性：直接修改引号内的文本
- CLUMP引用：修改 "_clump_name" 字段（填目标节点名称）
- 四维向量：修改 "_value" 数组，格式 ["x","y","z","w"]
- 改完后用 json -> bin 转回，再用文件对比验证

【翻译覆盖】
类名翻译: 863/863 (100%)
属性名翻译: 5059/5059 (100%)
支持地图: 104 个（所有主流地图）
翻译文件: zh字典.py（可独立更新补充）

【环境要求】
- Python 3.6 或更高版本
- 无需安装任何第三方库（仅使用 Python 标准库）
